# Celebration Mobile Web Page

A mobile-first celebration itinerary and menu page designed for GitHub Pages.

## Files
- `index.html` — all editable page content
- `style.css` — colours, fonts, spacing and layout
- `script.js` — small navigation enhancement

## Put it on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css` and `script.js` to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide your live website address.

## Editing
The itinerary is written directly in `index.html`, so you can change times, wording, menu items and ingredients whenever you want.

The colour palette and typography are in `style.css`.
